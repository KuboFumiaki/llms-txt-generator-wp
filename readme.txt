WordPressサイトのコンテンツからllms.txtを自動生成。AI（LLM）がサイト内容を理解しやすいMarkdown形式で出力します。

== Description ==

LLMs.txt Generator for WPは、WordPressサイトのコンテンツをAI・大規模言語モデル（LLM）が読みやすいllms.txt形式でサイトルートに自動出力するプラグインです。

ChatGPTやClaude、PerplexityなどのAIがサイトを参照する時代に向けて、サイトの構成とコンテンツの概要を1ファイルで伝えられます（LLMO / AI検索対策）。

= 主な機能 =

* **自動生成**: 投稿・固定ページの公開、更新、削除時に自動でllms.txtを更新（1リクエストにつき1回だけ実行される軽量設計）
* **手動生成**: 設定画面の「設定を保存してLLMS.txtを生成」ボタンひとつで保存と生成が完了
* **プレビュー**: 生成されたllms.txtの内容を設定画面でそのまま確認可能
* **出力対象の選択**: 出力する投稿タイプ・固定ページをチェックボックスで選択（公開設定の投稿タイプのみが対象）
* **並び替え**: 出力順序をドラッグ＆ドロップまたは矢印ボタンで変更可能
* **カテゴリ分類**: ブログ投稿はカテゴリ別に自動分類して出力
* **一覧ページの出力**: アーカイブを持つカスタム投稿タイプは一覧ページのURLも出力
* **賢い要約**: 各記事の要約は「手動抜粋 → SEOプラグインのメタディスクリプション（Yoast SEO / Rank Math）→ 本文の冒頭」の優先順で自動採用
* **カスタムテキスト**: ファイル上部に表示するテキストをMarkdownで自由に設定
* **文字コード選択**: UTF-8（デフォルト）またはShift-JISで出力

= 出力されるファイルの例 =

    # サイト名

    サイトの説明

    # 最終更新: 2026-07-07 12:00:00

    ## 固定ページ
    - [会社概要](https://example.com/about/):ページの要約...
      - [アクセス](https://example.com/about/access/):ページの要約...

    ## 投稿
    ### カテゴリ名
    - [記事タイトル](https://example.com/post-slug/):記事の要約...

    ## お知らせ
    - [お知らせ一覧](https://example.com/news/)
    - [お知らせタイトル](https://example.com/news/slug/):記事の要約...

= 使い方 =

1. プラグインを有効化すると、初回のllms.txtが自動生成されます
2. 「ツール」→「LLMs.txt Generator for WP」で出力内容をカスタマイズ
3. 画面下部の「設定を保存してLLMS.txtを生成」をクリック
4. `https://yoursite.com/llms.txt` でファイルを確認

== Installation ==

= 自動インストール =

1. WordPress管理画面で「プラグイン」→「新規追加」
2. 「LLMs.txt Generator for WP」を検索
3. 「今すぐインストール」→「有効化」

= 手動インストール =

1. プラグインのZIPファイルをダウンロード
2. 「プラグイン」→「新規追加」→「プラグインのアップロード」からZIPをアップロード
3. プラグインを有効化

有効化すると初回のllms.txtが自動生成され、「ツール」→「LLMs.txt Generator for WP」から設定できます。

== Frequently Asked Questions ==

= llms.txtはどこに保存されますか？ =

WordPressサイトのルートディレクトリ（wp-config.phpと同じ場所）に保存され、https://yoursite.com/llms.txt でアクセスできます。ファイルの書き込みにはWP_Filesystem APIを使用しており、サイトルートへの書き込み権限が必要です。書き込みに失敗した場合は設定画面にエラーが表示されます。

= 自動生成はいつ行われますか？ =

投稿・固定ページの公開、更新、削除のタイミングで自動的に実行されます。複数の処理が同時に走っても1リクエストにつき1回だけ生成される設計のため、サイトの動作への影響は最小限です。

= 各記事の要約はどこから取得されますか？ =

「手動で設定した抜粋 → SEOプラグイン（Yoast SEO / Rank Math）のメタディスクリプション → 本文の冒頭」の優先順で自動採用されます。

= どの投稿タイプが出力されますか？ =

公開設定（public）の投稿タイプのみが対象です。有効化時にすべての公開投稿タイプがデフォルトで選択され、設定画面で個別にオン・オフと並び替えができます。他のプラグインが内部的に使う非公開の投稿タイプが出力されることはありません。

= カスタム投稿タイプの一覧ページも出力できますか？ =

はい。アーカイブページを持つ（has_archiveが有効な）投稿タイプは、見出しの直下に一覧ページのURLが自動で出力されます。

= 新しく固定ページを公開した場合は？ =

公開と同時に自動で出力対象に追加され、llms.txtが更新されます。出力したくない場合は設定画面でチェックを外してください。

= 文字コードは変更できますか？ =

はい、UTF-8（デフォルト・推奨）またはShift-JISから選択できます。AIクローラはUTF-8を前提とすることが多いため、通常はUTF-8のままにしてください。

= アンインストールするとどうなりますか？ =

プラグインの設定データと、生成されたllms.txtファイルがすべて削除されます。
